# Contributing

This repository contains the source for the personal portfolio at mifdlal.com.
Contributions are limited to collaborators invited by the repository owner.

## Development

- Use the Node.js version declared by the project toolchain, when available.
- Install dependencies with `npm ci`.
- Run `npm run build`, `npm run typecheck`, and `npm run audit` before opening a PR.
- Keep portfolio claims evidence-based. Do not add projects, clients, credentials,
  or experience without owner verification.
- Keep changes focused, accessible, responsive, and compatible with the existing CSP.
- Never commit secrets, `.env` files, generated output, or local screenshots.

## Pull requests

Describe intent, user-visible changes, validation commands and results, and any
necessary screenshots. Link related issues. Do not include personal data or secrets.
